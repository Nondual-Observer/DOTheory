# Invariant, Pair, Triad and Types of Complement

Status: transitional research note to the DOT corpus.
It is not an entry point into the main core and does not fix the terminology
of Volumes \(0\)–\(6\). The current main presentation uses the six names of
rank \(3\):

\[
\{\text{background},\text{observer},\text{scene}\},
\qquad
\{\text{boundary},\text{content},\text{distinction}\}.
\]

The words "object" and "action" are retained in this note as a
research reading of the invariant, the pair and threeness. For the rigorous
corpus the preferred terms are "configuration", "axis", "boundary",
"content", "distinction", "observer".

This note refines the earlier formula "object as invariant of a pair".
The exact reading is deeper:

\[
\boxed{
\text{the invariant is a single entity;}
}
\]

\[
\boxed{
\text{on the carrier it is manifested as a pair of opposite states;}
}
\]

\[
\boxed{
\text{internally its minimal structure is threefold: a side, a side,
the invariant itself.}
}
\]

Therefore the numbers \(1,2,3\) in DOT are not three independent first
principles. They are three aspects of one structure:

\[
\boxed{
\begin{array}{c}
1=\text{the invariant itself};\\[3pt]
2=\text{its pairwise manifestation on the carrier};\\[3pt]
3=\text{its internal threefold structure}.
\end{array}
}
\]

---

# 1. The unit as the invariant itself

The unit in this note is read not as the first point of the carrier, but as a
single invariant entity.

\[
\boxed{
1=\text{the invariant itself}.
}
\]

In the language of the scene:

\[
I\in\operatorname{Inv}(S).
\]

The invariant belongs to the invariant structure of the scene, not to the
active carrier:

\[
\boxed{
I\in\operatorname{Inv}(S),
\qquad
I\notin X.
}
\]

This agrees with the observer formula:

\[
O_S\in\operatorname{Inv}(S),
\qquad
O_S\notin X.
\]

The unit therefore does not add a point to the carrier. It specifies what
is preserved under the reading of the carrier.

---

# 2. The pairwise manifestation of the invariant

The invariant is manifested on the carrier through a pair of opposite states:

\[
x\leftrightarrow \kappa x.
\]

The trace of the invariant on the carrier:

\[
\boxed{
\operatorname{Tr}_X(I_x)=\{x,\kappa x\}.
}
\]

The pair is the visible form of the invariant:

\[
\boxed{
2=\text{the manifestation of the invariant on the carrier}.
}
\]

In the active carrier \(U_n\) such a pair has the form:

\[
\{A,J_n\setminus A\}.
\]

Or:

\[
\{x,\kappa x\}.
\]

Its invariant notation:

\[
[x]=\{x,\kappa x\}.
\]

Therefore the minimal object is more precisely written as:

\[
\boxed{
\text{object}=[x]=\operatorname{Inv}\{x,\kappa x\}.
}
\]

The object is not one side of the pair, but the invariant stability of that
pair.

---

# 3. The threefold internal structure

The pairwise manifestation contains two sides:

\[
x,\qquad \kappa x.
\]

But holding this pair requires a third place: the invariant \([x]\) itself.

The minimal structure:

\[
\boxed{
x,\quad [x],\quad \kappa x.
}
\]

Or in general form:

\[
\boxed{
\text{side},\quad
\text{invariant},\quad
\text{opposite side}.
}
\]

This is the threeness of the minimal appearance of the object.

The visible manifestation of the object is binary:

\[
x\leftrightarrow\kappa x.
\]

The internal structure of objecthood is threefold:

\[
x,\ [x],\ \kappa x.
\]

In this way the earlier formula is refined:

\[
\boxed{
\text{the minimal object is manifested as a pair but held threefold.}
}
\]

---

# 4. Object and action as two readings of one structure

The earlier notation separated object and action thus:

\[
\text{object}=\text{invariant of the pair},
\qquad
\text{action}=\text{invariant of the triple}.
\]

The refined notation:

\[
\boxed{
\text{object and action are two readings of one invariant.}
}
\]

The object reading:

\[
[x]=\operatorname{Inv}\{x,\kappa x\}.
\]

The action reading:

\[
x\longrightarrow \kappa x
\quad
\text{while preserving }[x].
\]

That is, action is the transition between the sides while the invariant is
held:

\[
\boxed{
\text{action}=
\text{change of side while preserving the invariant of the pair}.
}
\]

The minimal action schema:

\[
\boxed{
x
\longrightarrow
[x]
\longrightarrow
\kappa x.
}
\]

Therefore action is threefold not because it requires a separate entity, but
because the transition between the two sides is read through the holding
invariant.

---

# 5. The formula \(1\cdot2\cdot3\)

The expression

\[
1\cdot2\cdot3
\]

is not an ordinary factorization of the carrier. It is a structural reading:

\[
\boxed{
1=\text{the invariant itself},
}
\]

\[
\boxed{
2=\text{the two sides of its manifestation},
}
\]

\[
\boxed{
3=\text{the threeness of the holding: side, invariant, side}.
}
\]

At rank \(3\) the active carrier has six points:

\[
|U_3|=6.
\]

Cardinally:

\[
6=3\cdot2.
\]

Structurally:

\[
\boxed{
U_3
\cong
I_3^{\mathrm{axes}}\times\{-,+\}.
}
\]

Here \(I_3^{\mathrm{axes}}\) are the three invariant axes:

\[
D,\quad F,\quad C.
\]

Each axis is a single invariant manifested by a pair of sides. Therefore
\(1\) is not counted as an additional point in \(U_3\). The unit is the
invariant place of each axis.

---

# 6. The three relations of rank \(3\)

On \(U_3\) there are three relations:

\[
(U_3,R_1)\cong C_6,
\]

\[
(U_3,R_2)\cong K_3\sqcup K_3,
\]

\[
(U_3,R_3)\cong 3K_2.
\]

In the refined reading:

\[
\boxed{
R_3=3K_2
}
\]

shows three invariants, each in the form of a pair of manifestations.

\[
\boxed{
R_2=K_3\sqcup K_3
}
\]

shows the threefold structure of the three invariants on two sides:

\[
S_1^{(3)}=\{100,010,001\},
\]

\[
S_2^{(3)}=\{110,101,011\}.
\]

The first layer gives one side of the three invariants, the second layer the
other side of the three invariants.

\[
\boxed{
R_1=C_6
}
\]

shows the traversal of all six manifestations.

In total:

\[
\boxed{
\begin{array}{c}
R_3:\text{three invariants as pairs};\\[3pt]
R_2:\text{the threeness of the three invariants on two sides};\\[3pt]
R_1:\text{the cyclic traversal of the six manifestations}.
\end{array}
}
\]

# 7. Why rank \(3\) is the first complete one

Rank \(1\) gives one polar coordinate:

\[
Q_1=\{0,1\}.
\]

Here there is a pair, but no room for three independent invariants.

Rank \(2\):

\[
Q_2=\{00,01,10,11\}.
\]

The active part:

\[
U_2=\{01,10\}.
\]

Here there is an active pair inside a two-dimensional carrier, but no
complete three-axis arrangement.

Rank \(3\):

\[
U_3=Q_3\setminus\{000,111\}.
\]

Here:

\[
U_3/\kappa=\{D,F,C\}.
\]

That is, for the first time there are three invariants, each manifested by a
pair:

\[
3\times2=6.
\]

Therefore:

\[
\boxed{
\text{rank }3\text{ is the first complete scene of the manifestation of }
1\cdot2\cdot3.
}
\]

---

# 8. Equality as the invariant of a pair

Equality is read as the held invariant of two distinguishable presentations.

Let there be two positions:

\[
a,\quad b.
\]

If they coincide in the invariant \(I\):

\[
I(a)=I(b),
\]

then equality arises:

\[
\boxed{
a=b\quad\text{in the invariant }I.
}
\]

In this way equality does not reduce to empty neutrality. It has a structure:

\[
\boxed{
\text{equality}=
\text{invariant of a pair of presentations}.
}
\]

The unit and equality differ:

\[
1
\]

is the invariant itself, while

\[
a=b
\]

is its manifestation as the coincidence of two presentations.

---

# 9. Limit instead of infinity

DOT works with finite carriers. Therefore the correct limit
formula uses a limit, not an actual infinity.

In the full rank-\(n\) carrier there is a limit pair:

\[
0^n,\qquad 1^n.
\]

In the language of subsets:

\[
\varnothing,\qquad J_n.
\]

The active carrier:

\[
U_n=Q_n\setminus\{0^n,1^n\}.
\]

Thus the active scene lies between the two limits of the full carrier.

The correct schema:

\[
\boxed{
\text{the invariant itself}
\leftrightarrow
\text{the limit of its unfolding}.
}
\]

The limit fixes the edge of the scene, relative to which the active region
becomes distinguishable.

---

# 10. The type of complement

In a simplicial carrier each active position has a complement:

\[
A\longleftrightarrow J_n\setminus A.
\]

This is a polar pair:

\[
\{A,\kappa A\}.
\]

Its type is determined by the sizes of the sides:

\[
|A|=k,\qquad |J_n\setminus A|=n-k.
\]

The type of complement:

\[
\boxed{
(k,n-k).
}
\]

This is a separate kind of distinction:

\[
\boxed{
\text{distinction by type of complement}.
}
\]

It distinguishes not the elements of the carrier, but the form of the
manifestation of the invariant on the carrier.

---

# 11. The growth of complement types

At rank \(2\):

\[
(1,1).
\]

This is the pure symmetry of the pair.

At rank \(3\):

\[
(1,2).
\]

This is the first asymmetric pair: an atom against the opposite edge.

At rank \(4\):

\[
(1,3),\qquad (2,2).
\]

Two types appear:

1. a vertex against the opposite face;
2. an edge against the opposite edge.

At rank \(5\):

\[
(1,4),\qquad (2,3).
\]

At rank \(6\):

\[
(1,5),\qquad (2,4),\qquad (3,3).
\]

The general line:

\[
\boxed{
1:1
\to
1:2
\to
1:3,\;2:2
\to
1:4,\;2:3
\to
1:5,\;2:4,\;3:3
\to\cdots
}
\]

The growth of the rank is the growth of complement types.

---

# 12. The distance between symmetry and asymmetry

The type \((1,1)\) is fully symmetric.

The type \((1,2)\) for the first time introduces an asymmetric complement.

The type \((1,3)\) strengthens the asymmetry.

The type \((2,2)\) returns the self-dual form at a new level.

A measure of asymmetry:

\[
\alpha(k,n-k)=|n-2k|.
\]

Examples:

\[
(1,1):\alpha=0,
\]

\[
(1,2):\alpha=1,
\]

\[
(1,3):\alpha=2,\qquad (2,2):\alpha=0,
\]

\[
(1,4):\alpha=3,\qquad (2,3):\alpha=1.
\]

Even ranks contain the self-dual type \((n/2,n/2)\).
Odd ranks do not contain it.

---

# 13. The projective quotient as a space of invariants

Each polar pair gives one object-invariant:

\[
\{x,\kappa x\}\mapsto[x].
\]

All such objects form:

\[
U_n/\kappa.
\]

Therefore:

\[
\boxed{
\operatorname{Obj}(U_n)=U_n/\kappa.
}
\]

And:

\[
\boxed{
U_n/\kappa\cong PG(n-2,2).
}
\]

Projective geometry in DOT receives an object reading:

\[
\boxed{
PG(n-2,2)=\text{the space of minimal objects of rank }n.
}
\]

The complement types \((k,n-k)\) stratify this space.

---

# 14. The example \(2\cdot2=2+2\)

The equality:

\[
2\cdot2=2+2.
\]

The result is the same:

\[
4.
\]

The operator paths are different:

\[
2\cdot2
\]

and

\[
2+2.
\]

The DOT reading:

\[
\boxed{
\text{one result can be the invariant of a pair of different actions.}
}
\]

\[
\operatorname{Inv}(2\cdot2,\;2+2)=4.
\]

This is an example of how an object appears as the place of coincidence of
different operator paths.

# 15. Final formula

The refined structure:

\[
\boxed{
\begin{array}{c}
1=\text{the invariant itself};\\[3pt]
2=\text{its pairwise manifestation};\\[3pt]
3=\text{its threefold holding};\\[3pt]
6=\text{three invariants, each in two manifestations}.
\end{array}
}
\]

Rank \(3\):

\[
\boxed{
U_3\cong I_3^{\mathrm{axes}}\times\{-,+\}.
}
\]

Three axes:

\[
\boxed{
U_3/\kappa=\{D,F,C\}.
}
\]

Three relations:

\[
\boxed{
R_3=3K_2
\quad\text{the pairwise manifestation of three invariants};
}
\]

\[
\boxed{
R_2=K_3\sqcup K_3
\quad\text{the threefold structure on two sides};
}
\]

\[
\boxed{
R_1=C_6
\quad\text{the traversal of six manifestations}.
}
\]

The main hypothesis of the note:

\[
\boxed{
\text{the minimal new object is a single invariant, manifested
on the carrier as a pair and held as a threefold structure.}
}
\]

In the current terminology of the main corpus this is read more cautiously:

\[
\boxed{
\text{a new stable unit of reading is an invariant, manifested
as a complementary axis.}
}
\]

Corollary:

\[
\boxed{
\text{the growth of the rank is the growth of the types of manifestation of the invariant through the complement}
(k,n-k).
}
\]
